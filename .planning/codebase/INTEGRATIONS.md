# External Integrations

## Editor Integrations
- **Unreal Python API (`unreal`)**: Used heavily inside python scripts such as `batch_retarget_reimu.py` and `diagnose_bp.py` to automate EditorAssetLibrary and AssetTools logic (batch renaming, property setups, component assignment).

## Web / Backend
- **None**: This project is exclusively a client-side game application. There are no REST APIs, databases, or third-party webhooks currently integrated.
