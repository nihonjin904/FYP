### Task 2 — 用 MCP 建立正確 Dodge AnimMontage（用 Doge_Combat_B_Seq 的 Reimu retarget）

<read_first>
確認以下 AnimSequence 存在（選擇最接近 Dodge 動作的）：
- `/Game/Sword_Animations/Animations/Sequence/06_Dodge/02_Dodge_Combat/Doge_Combat_B_Seq` — 原版（Sword_Animations skeleton）
- `/Game/Hit_B_Seq_Reimu` — Reimu 受擊（確認可播，但動畫錯誤）
</read_first>

<action>
**策略：** 由於 MCP 沒有 retarget 功能，需要在 UE5 Editor 手動 retarget `Doge_Combat_B_Seq` 到 Reimu skeleton，然後用 MCP 建立 montage。

**UE5 手動操作（約 3 分鐘）：**

**步驟 1：** Content Browser → 導航到：
`Sword_Animations/Animations/Sequence/06_Dodge/02_Dodge_Combat/`

**步驟 2：** 右鍵 `Doge_Combat_B_Seq`

**步驟 3：** 選 **`Retarget Animation Assets`** → **`Duplicate and Retarget Animation Assets/Blueprints`**

**步驟 4：** 右邊 Target Skeleton → 點 **`Select`** → 搜尋 **`SKEL__`** → 選 `SKEL__魔_博麗_霊夢`

（即 `/Game/Characters/reimu/SKEL__魔_博麗_霊夢`）

**步驟 5：** Output Location → 設為 `/Game/`（根目錄）

**步驟 6：** 點 **`Retarget`** → 等 10-30 秒

**步驟 7：** Content Browser 根目錄應出現 `Doge_Combat_B_Seq_Reimu`（或類似名稱）

**然後 MCP 自動建立 Montage：**（由 AI 執行，無需手動）

```
create_anim_montage(
  animation_path="/Game/Doge_Combat_B_Seq_Reimu",
  montage_name="AM_Dodge_Reimu",
  destination_path="/Game/",
  slot_name="DefaultGroup.DefaultSlot"
)
```
</action>

<acceptance_criteria>
- Content Browser 根目錄出現 `Doge_Combat_B_Seq_Reimu`（AnimSequence）
- Content Browser 根目錄出現 `AM_Dodge_Reimu`（AnimMontage，大小 > 8KB）
- `AM_Dodge_Reimu` 雙擊後預覽有 Dodge 動作（不是 T-pose）
</acceptance_criteria>

### Task 4 — 修正閃避手感（速度 + 距離）

<read_first>
- `Source/FYP/Public/Characters/SekiroCharacter.h` — 找 `DodgeLaunchSpeed` UPROPERTY（line ~429）
- 確認 `DodgeLaunchSpeed` 是 `EditAnywhere` UPROPERTY（可在 BP Class Defaults 即時調整）
</read_first>

<action>
**不需要修改代碼** — `DodgeLaunchSpeed` 已是 UPROPERTY，可在 BP 直接調整。

**步驟 1：** 打開 **`BP_SekiroCharacter`**（Content Browser 根目錄，雙擊）

**步驟 2：** 點擊頂部 **`Class Defaults`**（人形 icon）

（0.5 → 0.4，無敵幀短一點，更有挑戰性）

**步驟 6：** 點 **`Compile`** → **Ctrl+S**
