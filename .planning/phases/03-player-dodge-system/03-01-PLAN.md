# 03-01-PLAN.md — Phase 3: 玩家閃避系統

## Goal

玩家按 **Left Shift** 觸發閃避（Dodge Dash），主角面向 Boss 方向，
WASD 控制 dash 方向，閃避期間設 `bIsInvincible = true` 全程無敵，
有 Cooldown（1.0 秒）防止連閃。

### Task 5 — 實作 Dodge() 函數

<read_first>
讀 Source/FYP/Private/Characters/SekiroCharacter.cpp：
① 找到 StartBlock() 函數實作，了解如何取得 SekiroAttributeComponent（GetComponentByClass 或 Cast）。
② 找到現有 GetCharacterMovement() 用法。
③ 找到現有 GetWorld()->GetTimerManager().SetTimer() 用法（例如 PerilousAttackHitHandle）。

讀 Source/FYP/Public/Components/SekiroAttributeComponent.h：
確認 bIsInvincible 是 `UPROPERTY(BlueprintReadWrite)` 可以直接賦值。
</read_first>

<action>
**在 SekiroCharacter.cpp 尾部加入 Dodge() 函數實作：**

```cpp
// ===閃避系統===
void ASekiroCharacter::Dodge()
{
    // 1. Cooldown 檢查
    if (!bCanDodge || bIsDodging)
    {
        return;
    }

    // 2. 取得 AttributeComponent（用於無敵幀）
    USekiroAttributeComponent* AttrComp = GetComponentByClass<USekiroAttributeComponent>();
    if (!AttrComp)
    {
        UE_LOG(LogTemp, Warning, TEXT("Dodge: AttributeComponent not found!"));
        return;
    }

    // 3. 設定無敵幀
    bIsDodging = true;
    bCanDodge = false;
    AttrComp->bIsInvincible = true;

    // 4. 計算 dash 方向
    //    — 取玩家當前移動輸入方向（WASD）
    //    — 若無輸入，預設向後退（遠離 Boss 方向）
    FVector DodgeDirection = GetLastMovementInputVector();
    if (DodgeDirection.IsNearlyZero())
    {
        // 無 WASD 輸入 → 向角色正後方 dash
        DodgeDirection = -GetActorForwardVector();
    }
    DodgeDirection.Z = 0.0f;  // 確保水平
    DodgeDirection.Normalize();

    // 5. 施加 dash impulse
    LaunchCharacter(DodgeDirection * DodgeLaunchSpeed, true, false);

    // 6. DodgeDuration 後解除無敵幀
    GetWorld()->GetTimerManager().SetTimer(
        DodgeInvincibilityHandle,
        [this, AttrComp]()
        {
            bIsDodging = false;
            if (AttrComp)
            {
                AttrComp->bIsInvincible = false;
            }
        },
        DodgeDuration, false);

    // 7. DodgeCooldown 後允許再閃避
    GetWorld()->GetTimerManager().SetTimer(
        DodgeCooldownHandle,
        [this]()
        {
            bCanDodge = true;
        },
        DodgeCooldown, false);

    UE_LOG(LogTemp, Log, TEXT("[DODGE] Direction=%s | Invincible for %.1fs | Cooldown %.1fs"),
           *DodgeDirection.ToString(), DodgeDuration, DodgeCooldown);
}
```
</action>

<acceptance_criteria>
- SekiroCharacter.cpp 包含 `void ASekiroCharacter::Dodge()` 實作
- Dodge() 包含 `bIsInvincible = true` 和 Timer 在 DodgeDuration 後 reset
- Dodge() 包含 `bCanDodge = false` 和 Timer 在 DodgeCooldown 後 reset
- Dodge() 使用 `LaunchCharacter()` 施加位移
- Dodge() 使用 `GetLastMovementInputVector()` 計算方向，無輸入時 fallback 到 `-GetActorForwardVector()`
</acceptance_criteria>
