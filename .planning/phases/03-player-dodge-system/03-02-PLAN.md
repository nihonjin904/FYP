# 03-02-PLAN.md — Phase 3: 閃避動畫 Retarget

## Goal

解決 Skeleton 不相容問題，令 `PlayAnimMontage()` 能正確播放閃避動畫。

**根本原因：**

| 資產 | Skeleton |
|------|----------|
| `Doge_Combat_B_Seq`（閃避動畫） | `UE4_Mannequin_Skeleton`（KatanaAnimPack） |
| 玩家角色 `BP_SekiroCharacter` | `SK_Mannequin`（UE5 Mannequin） |

兩個唔同 Skeleton → `PlayAnimMontage()` 完全失效（無聲無息，位移有但動畫無）。

**解決方法：** 在 UE5 Editor 用 **Duplicate and Retarget** 把 `Doge_Combat_B_Seq` 轉換到 `SK_Mannequin` skeleton，再建立新 Montage 並 assign 到 BP。

---

## Tasks

### Task 1 — Retarget 閃避動畫到 SK_Mannequin Skeleton

<read_first>
Content Browser 確認以下路徑存在：
- `/Game/Sword_Animations/Animations/Sequence/06_Dodge/02_Dodge_Combat/Doge_Combat_B_Seq`（Source 動畫）
- `/Game/Characters/Mannequins/Meshes/SK_Mannequin`（Target Skeleton）
</read_first>

<action>
**步驟 1：** 在 Content Browser 左側導航到：

`Sword_Animations → Animations → Sequence → 06_Dodge → 02_Dodge_Combat`

**步驟 2：** 右鍵點擊 **`Doge_Combat_B_Seq`**

**步驟 3：** 在右鍵選單選擇 **`Retarget Animation Assets`**

**步驟 4：** 子選單出現，點擊 **`Duplicate and Retarget Animation Assets/Blueprints`**

**步驟 5：** 彈出 **「Retarget Animation Assets」** 視窗：

- 左邊（Source）應已顯示 `UE4_Mannequin_Skeleton`
- 右邊（Target）點擊 **`Select`** 按鈕
- 搜尋框輸入：**`SK_Mannequin`**
- 選擇：`/Game/Characters/Mannequins/Meshes/SK_Mannequin`

**步驟 6：** 視窗底部 **Output Location** 設定儲存路徑：

點擊資料夾圖示，選擇 `/Game/Characters/Sekiro/`

**步驟 7：** 點擊 **`Retarget`** 按鈕

等待完成（約 10-30 秒），Content Browser 的 `/Game/Characters/Sekiro/` 會出現新動畫。
</action>

<acceptance_criteria>
- `/Game/Characters/Sekiro/` 目錄下出現 `Doge_Combat_B_Seq`（或類似名稱，帶 `_Retargeted` 後綴）
- 雙擊新動畫，Preview 面板能正確預覽角色動作（不是 T-pose）
</acceptance_criteria>

### Task 4 — 加入 PlayAnimMontage 到 Dodge() 函數

<read_first>
讀 `Source/FYP/Private/Characters/SekiroCharacter.cpp`：
找到 `void ASekiroCharacter::Dodge()` 函數實作（約在尾部）。
確認是否已有 `PlayAnimMontage(DodgeMontage)` 呼叫。
</read_first>

<action>
**情況 A：Dodge() 已有 PlayAnimMontage → 跳過此 Task。**

**情況 B：Dodge() 未有 PlayAnimMontage → 在 `LaunchCharacter()` 呼叫之後加入：**

```cpp
// 播放閃避動畫
if (DodgeMontage)
{
    PlayAnimMontage(DodgeMontage, 1.0f);
}
else
{
    UE_LOG(LogTemp, Warning, TEXT("[DODGE] DodgeMontage is NULL — assign in BP Class Defaults"));
}
```

確認 `SekiroCharacter.h` 有以下宣告（應已在 Plan 03-01 加入）：

```cpp
UPROPERTY(EditAnywhere, Category="Sekiro|Dodge")
TObjectPtr<UAnimMontage> DodgeMontage;
```

若無 → 在 header 的 Dodge 相關區塊加入。
</action>

<acceptance_criteria>
- `SekiroCharacter.h` 包含 `TObjectPtr<UAnimMontage> DodgeMontage` UPROPERTY
- `SekiroCharacter.cpp` 的 `Dodge()` 包含 `PlayAnimMontage(DodgeMontage, 1.0f)`
- Build 成功（UE5 Editor Compile 無 Error）
</acceptance_criteria>

<read_first>
確認 Task 1-4 全部完成且儲存。
確認 UE5 Editor 已 Compile 成功。
</read_first>

<action>
**步驟 1：** 按 **Play 按鈕** 進入 Play 模式

**步驟 2：** 靠近 Boss，按 **Left Shift**

**預期結果：**

- ✅ 角色有明顯 **dash 位移**（Task 03-01 的 LaunchCharacter）
- ✅ 角色同時播放 **Roll / Dodge 動畫**（新 AM_Dodge_Player）

1. 打開 Output Log（視窗底部），搜尋 `[DODGE]`
2. 若出現 `DodgeMontage is NULL` → Task 3 未正確 assign，重做 Task 3
3. 若無任何 `[DODGE]` 訊息 → Shift 輸入未綁定，重做 03-01 Task 2
</action>

<acceptance_criteria>

- 1 秒內連按 Left Shift 只觸發一次
